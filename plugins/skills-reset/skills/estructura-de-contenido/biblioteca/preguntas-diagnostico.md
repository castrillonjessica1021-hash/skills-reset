# Banco de preguntas de diagnóstico

Preguntas para sacarle a la alumna el material real antes de escribir nada — nunca inventar
las respuestas en su lugar. Usar las que apliquen al momento (no las 16 de una sentada).

| Tema | Pregunta |
|---|---|
| Objetivo | Si Instagram desapareciera mañana, ¿qué resultado seguirías queriendo de tu reputación? |
| Audiencia | ¿Quién tiene el problema que tu experiencia resuelve mejor? |
| Percepción | ¿Qué tres cosas quieres que alguien diga de ti sin que tú se las hayas dicho? |
| No-percepción | ¿Qué te dolería que se volviera la principal asociación con tu nombre? |
| Prueba | ¿Qué has hecho que demuestre que puedes hablar de esto? |
| Falta de prueba | ¿Qué necesitas hacer en el mundo real para tener algo más fuerte que decir? |
| Problema | ¿Qué frase exacta repiten clientes, leads o seguidores? |
| Costo | ¿Qué pierde la persona si no resuelve esto? |
| Criterio | ¿Qué haces distinto de la solución típica? |
| Creencia | ¿Qué consejo popular de tu sector no compras del todo? |
| Contenido | ¿Qué parte de tu trabajo nunca enseñas y sería útil ver? |
| Humanidad | ¿Qué elemento de tu vida ayuda a entender por qué piensas como piensas? |
| Sostenibilidad | ¿Qué formato podrías repetir 50 veces sin odiarlo? |
| Delivery | ¿Cómo explicas esto en una llamada cuando no estás intentando sonar "profesional"? |
| Métrica | ¿Qué te importa más en esta etapa: views, leads, conversaciones, ventas, confianza, prueba? |
| Fase de lanzamiento | ¿En qué fase estás: precalentamiento, anticipación, educación, objeciones, apertura, cierre o post-lanzamiento? |
| Objeción real | ¿Qué duda u objeción repite más la gente que no ha comprado? |
| Transformación | ¿Qué cambia de verdad en la vida o el negocio de quien compra, más allá de lo que incluye la oferta? |

Si la alumna no tiene respuesta clara a una pregunta clave para lo que está pidiendo, se le
pregunta directamente en vez de rellenar con algo genérico.
